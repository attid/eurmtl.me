# ИИ-помощник eurmtl.me (чат на сайте)

Статус: **план, согласован владельцем 2026-10-11**; реализация по этапам,
каждый этап — отдельный коммит/PR. Старт — по «ГО».

## Вводные (решения владельца)

- Для **всех юзеров** сайта; логин — существующая Stellar-сессия
  (`/login/agent` / TG-login, 7 дней).
- Ключ LLM — **владельца** (Anthropic-аккаунт), на первое время модель
  **Grok** (xAI, OpenAI-совместимый API) → провайдер через адаптер, замена
  модели = одна строка конфига.
- **Не Telegram** (пока не передумал) — **чат на сайте**.
- Роль: помощник **создания вопросов и черновиков**; публикация — всегда
  руками юзера (кнопкой в UI), агент не публикует.
- Читает: вопросы/чтения/шаблоны (Grist), **транзакции** (need_sign,
  get_xdr, XDR↔JSON) и **лабу** (`/lab/build_xdr` — пересборка транзы).
- Фреймворк: рассматривался **AG2** (pypi ag2 1.1.2); решение — на старте
  **ванильный tool-call цикл** (0 зависимостей, ~150 строк), AG2 прицепить
  при появлении мульти-агентных сценариев.
- **Сессии**: короткие — в памяти процесса, TTL ~2ч после последнего
  сообщения; при рестарте умирают (осознанно: «неделю назад» не храним).
- **Микро-память пользователя**: да (несколько фактов о юзере, персист в
  Grist-таблицу AI_USER_MEMO: user, facts, updated).

## Архитектура

```
Браузер юзера (сессия уже есть)
   │
/assistant                 страница-чат
/assistant/api/message     POST {text} → ответ (SSE-стрим — этап 5+, синхр. — этап 1)
   ▼
services/assistant/
   ├─ session_store        in-memory, TTL 2ч, {user_id: messages[]}
   ├─ user_memo            микро-память: Grist AI_USER_MEMO, факты в system prompt
   ├─ system_prompt        роль + орги юзера (_user_visible_orgs) + правила
   ├─ tools                (сгруппированы по правам сессии)
   │    read:  questions_list(org, status, q), question_get(uuid),
   │            templates_list(), tx_pending(account), tx_get_xdr(hash),
   │            xdr_to_json()
   │    write: draft_create(org, number, title, body, reading, status)
   │            draft_update(uuid, body, status)     — только черновики
   │            build_xdr(payload)                   — XDR юзеру, не подписывает
   │    НЕТ: publish, patch TELEGRAM_LINK, чужие орги
   ├─ llm                  OpenAI-совместимый клиент (xAI Grok → заменяемо)
   └─ audit                logger.info на каждый tool-call (паттерн проекта)
```

## Безопасность

- Скоуп инструментов = права сессии (орги, edit_allowed — как в d2).
- Агент не публикует: «Опубликовать» — кнопка юзера; TELEGRAM_LINK агент
  не пишет.
- XDR: агент только собирает; подпись — юзер через sign_tools.
- LLM-ключ: env сервера, в гит не попадает.
- Rate-limit на юзера (сообщений/мин) — защита от расходов токенов.

## Этапы

1. **Каркас**: `/assistant` + `/assistant/api/message`, ванильный цикл
   tool-calls, Grok через OpenAI-SDK, read-инструменты questions_list /
   question_get / templates_list. Примитивный чат-UI без стрима.
2. **Действия**: draft_create / draft_update с орг-гейтами и аудитом.
3. **Транзакции + лаба**: tx_pending, tx_get_xdr, xdr_to_json, build_xdr.
4. **Микро-память**: AI_USER_MEMO (Grist) + запись фактов после сессий.
5. (опция) SSE-стрим, AG2/мульти-агент, новые модели.
