## Context — решения владельца (хронология 2026-10-09)

1. **Grist под десижены строим с нуля**, «как будто Gristа нет и в помине»:
   структура создается свежей, той которая нужна. Старый кириллический
   контент («Фонд», «МТЛА», «ЮЗДМ») — не святыня. Остальной Grist не трогаем:
   секретари остаются в `EURMTL_secretaries` (док `3Fk4hjCv847GBx8ZTCPN2Y`),
   как сейчас.
2. **Дорожная карта**: D2 доводим на тесте → выкатываем на прод **без пункта
   в меню**, владелец тихо протыкивает → потом D1 мигрируем на Grist с этой
   структурой → D подменяем на D2 (возможно сразу, без промежутка).
3. **Организации — ровно 4 (+ могут добавляться при заполнении)**. Названия
   новые, латиницей: **PFM, TFM, USDMM, MTLA, GORA** (пять; владелец: «может
   и больше будет в процессе заполнения»). Старые кириллические — плохие,
   уходят.
4. **Все ID боевые, фейковых нет** — владелец даёт адреса и каналы; подмен
   тест/прод не нужно: на стенде Telegram эмулируется (`/dev/tg-log`),
   мок принимает любой chat_id.
5. **Воркспейс-модель вместо комбиков.** Нынешний UX («система продвижения
   вопросов + свойство организация») не нравится: пришёл работать с MTLA —
   весь d2 живёт в MTLA, другие организации не видны и не отвлекают.
   - Вход `/d2`: видимых орг больше одной → экран выбора воркспейса (вариант
     «а»); ровно одна → сразу в неё; ноль → пустой экран «у вас нет
     организаций».
   - Чужие deep-links `/d2/<uuid>`: аноним — отказ; авторизованный с
     доступом — открывает; без доступа — отказ.
6. Реальные данные (владелец, 2026-10-09): PFM = фонд из D1; GORA и USDMM —
   см. конфиг ниже. TFM — владелец заполнит позже «в исходники». «Этого
   хватит до релиза».

```python
@dataclass(frozen=True)
class Org:
    name: str
    main_address: str          # "" = заглушка: не видна никому, кроме секретарей

    readings: int              # 0 = одно чтение, один канал на любое

        ("84131737",), 3),          # один канал на 3 чтения
    Org("USDMM", "GDHDC4GBNPMENZAOBB4NCQ25TGZPDRK6ZGWUGSI22TVFATOLRPSUUSDM",
        ("1789207509",), 0),        # одно чтение; канал -1001789207509
    Org("TFM", "", (), 0),          # TODO(владелец): адрес, канал, чтения
)
```

- PFM: `main_address` = `main_fund_address` (`services/stellar_client.py:32`),
  каналы = `DEFAULT_FUND_CHAT_IDS[1:]` (`grist_tools.py:387`).
- Логика выбора канала без изменений (`grist_tools.py:406-438`):
  `readings>0` → `channels[min(reading, len)-1]` (GORA: всегда [0]);
  `readings<=0` → `channels[0]` (USDMM).
- `DEFAULT_ORG_NAME` («Фонд») уходит: PFM — имя дефолта в конфиге
  (`DEFAULT_ORG_NAME = "PFM"` в `orgs_config.py`; в `grist_tools.py` оставить
  реэкспорт, чтобы не трогать `decision.py:28`).
- Валидация конфига на импорте: имена уникальны, непустые имена, каналы
  непусты **если** адрес непуст (TFM-заглушка разрешена), readings >= 0.

## Задача 2 — воркспейс-модель (UX)

1. **Выбор и хранение**: сессия `session["d2_org"]`.

     redirect на список; нет → видимая одна орга → set+redirect; ноль →
     пустой экран «У вас нет организаций» (новый шаблон `d2_workspace.html`);
     больше одной → экран выбора (тот же шаблон, список кнопок-кард).
   - `POST /d2/workspace` (form: `org`) → валидация видимости → set →
     redirect на список. Переключатель в шапке — форма с этим роутом
     (select+submit или dropdown-link'и).
2. **Скоупинг страниц** (везде org = `session["d2_org"]`, при невалидной —
   redirect на `/d2`):
   - список `/d2/fragment/edit`: убрать org-фильтр-комбик и колонку «Орг»;
     показывать только вопросы текущей орги;
   - форма `/d2/fragment/form`: убрать комбик «Организация»; org формы =
     воркспейс (рендер `org=`); выбор шаблона подставляет только тему/тело;
   - пикер `/d2/fragment/new`: шаблоны только текущей орги (чужие прячутся
     целиком, без серого состояния — решение владельца, раунд 1 Q4);
     колонку «Организация» не добавлять (воркспейс и так её задаёт),
     colspan empty-state не трогается (колонок осталось 3);
   - прямой `/d2/fragment/form?template_id=X` чужой орги → шаблон
     игнорируется (чистая форма), POST всё равно прикроет гейтом.
   - экран вопроса `/d2/<uuid>`: гейт не по сессии, а по доступу к орге
     вопроса (`_org_visible(question.ORG)`) — deep-link открывается, если
