# D2: публичный embed-список вопросов по токену орги

Создан 2026-11-03. Контекст: старый гугло-док `MTL_decisions` (лист MTLFUND)
публично встраивали фреймом на сторонний сайт; от d2 хотят того же — но не для
всех орг и **без текстов вопросов**: только № / тема / статус / ссылки на
TG-посты чтений. Решение владельца 2026-11-03: токен орги хранится в Grist
(не в публичном git), первым включается PFM.

## Дизайн

- **URL**: `GET /d2/pub/<token>` — анонимный read-only, без сессии.
  Токен — 32 hex (`secrets.token_hex(16)`), владелец генерит и вписывает в
  Grist руками. Нет совпадения → 404 (одинаковый ответ для любого неверного
  токена, без перечисления орг).
- **Хранилище токена**: таблица `D2_PUBLIC` в eurmtlme-доке
  (`3Fk4hjCv847GBx8ZTCPN2Y`), колонки `ORG` (text), `TOKEN` (text).
  Ротация = правка ячейки в Grist UI, без деплоя. В `orgs_config.py`
  секретов нет — файл публичный.
- **Данные**: `D2_QUESTIONS` (ORG == орге токена) × `D2_QUESTION_DATA`
  (по QUESTION_ID). Публично только чтение с непустым `TELEGRAM_LINK`;
  вопрос без опубликованных чтений — не показывается (черновики невидимы).
  `BODY`, `CREATED_BY`, `UUID`, `EXTRA` — не рендерятся нигде.
- **Рендер**: отдельный standalone-шаблон (не tabler_base — меньше шума во
  фрейме): таблица «№ | Тема | Статус | Чтения (ссылки на TG-посты)»,
  сортировка № desc, чтения asc. Статус — из последнего опубликованного
  чтения. TG-ссылки `t.me/c/...` открываются только членам канала — как
  было в гугло-доке.
- **Заголовки** на этом роуте: `X-Robots-Tag: noindex, nofollow` +
  `Content-Security-Policy: frame-ancestors *` (токен и есть граница; при
  желании сузим до конкретного сайта). `X-Frame-Options` в репо никто не
  ставит (проверено grep 2026-11-03) — переопределять нечего.
- **Запись в Use_log**: нет — у роута нет сессии/юзера.
- Не в скоупе: страницы-каталог публичных орг, экспорт, RSS, разграничение
  колонок per-org.

## Файлы (воркер)

1. `other/grist_tools.py` — `D2_PUBLIC = GristTableConfig("3Fk4hjCv847GBx8ZTCPN2Y", "D2_PUBLIC")`.
2. `routers/d2_public.py` (новый) — blueprint, роут `/d2/pub/<token>`,
   чтение `D2_PUBLIC`/`D2_QUESTIONS`/`D2_QUESTION_DATA` через `grist_cache`
   (5с TTL уже есть), сборка списка, заголовки, рендер.
3. `start.py` — регистрация blueprint (1 строка).
4. `templates/d2_public.html` (новый) — standalone, inline CSS, без JS.
5. `tests/fixtures/d2_stand_seed.json` — таблица `D2_PUBLIC` (PFM +
   тестовый токен `test_public_token_pfm`); dev-стенд должен отдавать её
   как обычную таблицу.
6. `tests/routers/test_d2_public.py` (новый) — кейсы:
   - валидный токен → 200; в HTML есть TITLE и t.me-ссылки, нет текста BODY;
   - неверный/чужой токен → 404;
   - вопрос-черновик (пустой TELEGRAM_LINK) не виден;
   - TFM (нет строки в D2_PUBLIC) недостижим;
   - заголовки `X-Robots-Tag`, `Content-Security-Policy` присутствуют;
   - org без токена → нет способа получить список.

## Ручной шаг владельца (прод)

Создать в eurmtlme-доке таблицу `D2_PUBLIC`: колонки `ORG`, `TOKEN`; строка
`PFM | <токен>` (генерить: `python -c "import secrets;print(secrets.token_hex(16))"`).

## Приёмка

- `uv run pytest tests/ --no-cov -q` — 0 failed; `ruff format --check`, `ruff check`.
- Стенд :8000: `/d2/pub/<seed-токен>` — список PFM, тела нет; кривой токен — 404.
- `curl -sI` — оба заголовка на месте.
- Embed-смоук: локальная html-страница с `<iframe src="...">` — фрейм рендерится.
- Воркспейс-гейты `/d2*` не задеты (тесты существующие зелёные).

## Деплой

Код мёржится в master; в прод попадает с очередным деплоем владельца
(гугло-фрейм заработает после ручного шага — создания `D2_PUBLIC`).
