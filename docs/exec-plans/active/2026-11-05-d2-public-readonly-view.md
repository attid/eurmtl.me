# 2026-11-05 — D2: публичный read-only просмотр вопроса по ссылке

Инцидент: читатель канала открыл «Edit on eurmtl.me» из поста без логина —
получил «Decision not exist =(» (гейт `cmd_d2_show`: аноним → 404 до
обращений к Grist, в логах следа нет). В d1 по ссылке могли редактировать
все — владелец подтвердил: правка для всех «не секретно», закрываем.

Решение владельца (вариант B, 2026-11-05): **аноним по ссылке читает
вопрос** (read-only), правки — только своим (гейты не меняются). Барьер
подбора ссылок: UUID 32-hex, неугадываемый. Палить существование
несуществующих uuid по-прежнему не нужно: не найден → 404 как раньше.
Существование ссылок из постов уже публично — скрывать нечего.
BODY вопроса становится публичным по ссылке — осознанное решение
владельца (в d1 BODY и редактировался всеми).

## Изменения

- `routers/decision.py` `cmd_d2_show`:
  - аноним (userdata None): ищем строку; не найдена → 404 (как раньше);
    найдена → рендер read-only, гейт видимости орги для анонима НЕ
    применяется (по ссылке читается любая орга);
  - залогиненный: гейты прежние (чужая орга → 404 «как несуществующая»);
  - `readonly_view` в контекст шаблона; user_weight для анонима и так 0
    (`_d2_edit_allowed` без сессии → False), POST-ветка гейтится
    `user_weight > 0` — мутаций нет.
- `templates/d2_question.html`: анониму НЕ показываем шапку воркспейса
  (`d2_header_buttons`), «← К списку вопросов», кнопки «Копировать»/
  «Сохранить как шаблон»/«Создать транзакцию» и их модалки. Показываем:
  тему/статус/тело (readonly: `disable_fields` уже от user_weight<1),
  навигацию чтений (с бейджем «черновик»), кнопки «Открыть в Telegram».
- Подпись ссылки-подвала постов: «Edit on eurmtl.me» → «Открыть на
  eurmtl.me» (readers-читатели не «editят»; в get_full_text и
  _d2_rich_blocks).
- После логина юзер возвращается на вопрос: `return_to` уже
  подхватывается логин-флоу (index.py), менять нечего.

Явные решения (можно перевернуть):
- черновики: аноним с ссылкой на черновик видит его read-only с бейджем
  «черновик» (ссылка неугадываемая, распространение — на совести членов);
- орги-заглушки с пустым main_address (TFM) — по ссылке тоже читаются.
