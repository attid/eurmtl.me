# 2026-11-11 — D2: тип публичного списка (PUBLIC_VIEW) в Grist

Задача владельца: публичный embed-список `/d2/pub/<token>` должен уметь
показывать не всё, а только закрытые вопросы. Тип задаётся настройкой
в Grist, чтобы менять его без деплоя.

Решение владельца (2026-11-11):
- режим применяется **только к embed-списку** (`/d2/pub/<token>`);
  анонимный read-only `/d2/<uuid>` и воркспейс не трогаем;
- закрытость — «вопрос в третьем чтении и статус `✅ #done`»:
  последнее опубликованное чтение = 3 **и** его STATUS = `✅ #done`.
  `🔂 #resign` и `🔇 #canceled` закрытыми не считаются;
- «нужно только там, где 3 чтения»: у орг с одним чтением (USDMM/TFM)
  вопрос никогда не попадает в режим 2 — список будет пустым, это
  ожидаемо и обратимо.

## Дизайн

- **Хранение**: колонка `PUBLIC_VIEW` (Int) в существующей таблице
  `D2_PUBLIC` — там же, где `ORG`/`TOKEN`. Схему и значения владелец
  правит руками в Grist UI, код схему не создаёт.
- **Значения**: `1` (и пусто/мусор/любое число вне enum) — как раньше,
  все вопросы с опубликованным чтением; `2` — только закрытые.
  Битое значение не ломает страницу и не прячет список молча.
- **Предикат**: `readings[-1].READING == 3 and STATUS == "✅ #done"`
  (чтения уже отсортированы по возрастанию; в список попадают только
  строки с валидным `TELEGRAM_LINK`, как и раньше).
- **Рендер** не меняется: у закрытого вопроса по-прежнему все ссылки
  чтений 1..3 и статус последнего чтения.
- **Кеш**: тот же `public_tables_cache` (5с) — правка ячейки в Grist
  подхватывается без деплоя.

## Файлы

- `routers/d2_public.py` — `D2_PUBLIC_VIEW_*`, `D2_CLOSED_*`,
  `_public_view_mode`, `_question_is_closed`; в роуте строка `D2_PUBLIC`
  теперь ищется целиком (нужна `PUBLIC_VIEW`, а не только `ORG`);
  фильтр в цикле сборки items; docstring модуля.
- `tests/routers/test_d2_public.py` — режим 2 (только закрытый вопрос,
  пустой список, `🔇 #canceled`), дефолт режима 1 на мусорных ячейках,
  чтение номера режима из int/float/строки с пробелами.
- `tests/fixtures/d2_stand_seed.json` — `PUBLIC_VIEW: 1` в строке PFM
  (схема стенда = прод-схема, поведение стенда прежнее).

## Ручной шаг владельца (прод)

Добавить в таблицу `D2_PUBLIC` колонку `PUBLIC_VIEW` (Int) и вписать `2`
в строку орги, которой нужен «только закрытый» список.

## Приёмка

- режим 2: в HTML только вопрос 3-го чтения со статусом `✅ #done`;
  вопрос с `✅ #done` на 2-м чтении, с активным 3-м чтением и с
  `🔂 #resign`/`🔇 #canceled` — скрыт;
- в режиме 2 нет закрытых → «Опубликованных вопросов нет», код 200;
- `PUBLIC_VIEW` = `None`/`""`/`"мусор"`/`1`/`0`/`3`/`-1`/`True` → режим 1
  (текущее поведение, существующие тесты зелёные);
- `LOGIN`-гейт правок и анонимный `/d2/<uuid>` не затронуты;
- ruff format/check, pyright, pytest, `just arch-test`.

## Риски

- Орга с одним чтением в режиме 2 всегда отдаёт пустой список — это
  следствие правила «третье чтение»; решается правкой ячейки обратно на 1.
- Статус из ручной ячейки сравнивается после `strip()`; внутренние
  двойные пробелы (`✅  #done`) закрытыми не считаются — статусы пишет
  форма сайта/MCP из фиксированного списка.
