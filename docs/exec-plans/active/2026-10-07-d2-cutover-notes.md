# Баг: тело не редактируется при создании из лендинга (/d2 → Создать → Выбрать)

## Симптом (владелец, m00797)
«жму создать - простой - меняю тему не могу изменить тело».

## Причина
- Лендинг `/d2` (templates/d2_index.html) — SPA-подобная страница на htmx:
  кнопки hx-get → фрагменты в #d2-panel.
- Фрагмент-роут `/d2/fragment/form` рендерит ПОЛНЫЙ шаблон d2_form.html
  (extends tabler_base.html, 153 строки), htmx вставляет его innerHTML в
  #d2-panel.
- Внутри — quill-инициализация в {% block bottom_scripts %} + CDN-скрипты в
  head_scripts. При htmx-вставке:
  - <script> из блока НЕ исполняется контекстно? — исполняется, но НЕ в этом
    дело: рендер full-страницы внутрь div тянет за собой <html>/<head>/<body>
    разметку, браузер вырезает вложенный <html>, а скрипты блока
    bottom_scripts частично теряются.
- Проверено live через orca exec на http://localhost:8000/d2 после клика
  Создать → Выбрать (Простой вопрос):
  - typeof Quill → "undefined" (CDN-скрипт quill.js не загружен — его тег жил
    в вырезанном <head>);
  - .ql-editor в DOM → 0;
  - #editor-container.children[0] → сырой <P> (исходный контент), не .ql-editor.
- Т.е. темы можно править (обычный <input>), а тела нельзя (quill так и не
  инициализировался). Форма при сабмите возьмёт пустой inquiry.

## Почему через список работает (обошли)
Список /d2/fragment/edit: строки-<a href> = НАВИГАЦИЯ (полная загрузка
/d2/<uuid> как обычной страницы) — там quill инициализируется нормально.

## Варианты фикса
1. Фрагмент-роуты отдают фрагменты без extends (как d2_frag_new/edit), а
   quill+скрипты подключать на лендинге (head_scripts d2_index.html) +
   инициализация через htmx.on('htmx:afterSwap'). Чище, но меняет структуру
   d2_form/d2_question.
2. Из лендинга вести на форму НАВИГАЦИЕЙ (window.location / обычная ссылка),
   не htmx-панелью. Минимальный дифф, но ломает SPA-идею лендинга.
3. d2_form/d2_question рендерить фрагментом И страницей: condition на
   HX-Request header (htmx шлёт HX-Request: true). Классический паттерн
   quart+htmx.

Выбор: вариант 3 — форма/вопрос остаются полноценными страницами при прямой
навигации и фрагментами при htmx; скрипты quill вынести в оба режима.
